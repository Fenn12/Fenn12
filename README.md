### 陈超 · Chen Chao

市场营销硕士在读（宁波诺丁汉大学，2027.11 毕业）。目前做电商与内容运营，重点在**把内容生产从靠手感变成可评测的流水线**。

**关心的几个问题**

- 模型编出一个不存在的人群画像时，怎么让它在流程里先停下来问
- 改了 prompt 之后，怎么知道是变好还是悄悄弄坏了别的场景
- 自动分层能算出贡献，但算不出战略价值——这条边界该划在哪
